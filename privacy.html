개인정보 처리방침

신수첩 · 최종 수정일 2026년 11월 21일

입력한 생년월일을 개발자 서버로 보내지 않습니다. 계정과 로그인은 없으며, 역법 계산과 콘텐츠 열람은 기기 안에서 이루어집니다. 1.1.0부터 어떤 화면을 몇 번 열었는지만 익명으로 보내는 사용 통계가 들어갔고, 설정에서 끌 수 있습니다(2절).

이 방침은 자동 업데이트 통신을 비활성화한 1.1.0 이후 빌드를 기준으로 합니다. 이전에 설치한 빌드의 차이는 5절에 적었습니다.

1. 수집하지 않는 것

다음 정보는 개발자 서버나 분석·광고 서비스로 전송하지 않습니다.

  • 이름, 이메일, 전화번호, 주소 등 신원 정보
  • 기기 식별자, 광고 식별자(IDFA), 위치 정보, IP 주소 저장
  • 이용자가 입력하거나 고른 값 — 생년월일, 띠, 토정비결 괘, 궁합 상대, 고른 날짜, 「내 사람들」에 담은 별명
  • 연락처, 사진, 캘린더 등 기기 내 다른 데이터
  • 오류 보고(크래시 리포트) 도구

2. 익명 사용 통계

어느 기능이 실제로 쓰이는지 알기 위해 1.1.0부터 화면을 열고 단추를 누른 횟수만 익명으로 보냅니다. 광고나 이용자 식별을 위한 추적이 아닙니다.

보내는 것

  • 앱을 처음 연 날짜, 앱을 연 날의 수, 마지막으로 연 날짜 (날짜까지만, 시각은 보내지 않습니다)
  • 화면별로 몇 번 열렸는지 — 오늘의 신수, 달력, 신수, 더보기, 원형 휠, 띠 궁합, 토정비결, 날짜 고르기, 절기 일람, 용어 풀이, 내 사람들
  • 생년월일 입력 화면에 들어온 횟수와 저장을 마친 횟수 (입력한 날짜 자체는 보내지 않습니다)
  • 알림 권한을 물었는지와 허용했는지(예·아니오)
  • 앱 버전, 운영체제 종류(iOS·Android), 앱 언어
  • 설치할 때 기기에서 만든 무작위 번호 — 같은 기기의 기록을 모으기 위한 것이며 이용자를 알아낼 수 없고, 앱을 지우면 사라집니다

목적 기능 개선 우선순위 판단(통계·분석). 이용자에게 맞춘 광고나 프로파일링에 쓰지 않으며 제3자에게 제공·판매하지 않습니다.

보관 개발자가 운영하는 Cloudflare Workers·D1(아시아·태평양)에 기기별 한 줄로 보관하며, 같은 무작위 번호의 기록을 덮어씁니다. 처리는 Cloudflare 개인정보 정책을 따릅니다.

끄는 방법 설정 → 「익명 사용 통계 보내기」를 끄면 그때부터 아무것도 보내지 않고 기기 안에서도 더 쌓지 않습니다. 전송 주소가 비어 있는 빌드는 애초에 보내지 않습니다.

3. 기기에만 저장되는 것

이용자가 입력한 생년월일은 띠와 토정비결을 계산하기 위해 앱의 기기 내 저장소에 보관됩니다. 화면을 펼친 날짜 등 표시 상태도 기기에 저장될 수 있습니다. 앱은 이 값을 개발자 서버로 전송하지 않습니다.

설정에서 생년월일을 변경하거나 지울 수 있습니다. 앱을 삭제하면 해당 기기의 앱 데이터가 제거됩니다. 다만 운영체제의 백업·복원 설정에 따라 앱 데이터가 백업되거나 새 기기에 복원될 수 있으며, 앱 안에서 지우는 동작이 이미 만들어진 운영체제 백업까지 삭제하지는 않습니다.

4. 제3자 도구

앱 실행·저장·이미지 표시·공유·알림에 React Native와 Expo 라이브러리를 사용합니다. 광고·이용 분석·소셜 로그인 SDK는 넣지 않았습니다(결제 처리 도구는 7절에 적었습니다) — 2절의 사용 통계는 제3자 분석 도구를 쓰지 않고 개발자가 직접 만든 것으로, 위에 적은 항목만 보냅니다. 새 빌드에서는 Expo의 자동 업데이트 기능을 비활성화했습니다.

5. 업데이트와 외부 통신

자동 업데이트 통신을 끈 새 빌드는 앱 실행 시 Expo 서버에 업데이트를 요청하지 않습니다. 새 버전과 콘텐츠 수정은 App Store 또는 Google Play의 앱 업데이트로 제공합니다. 오늘의 신수는 기기에 포함된 문안과 날짜로 정해지므로 인터넷 없이도 날짜에 맞춰 볼 수 있습니다.

이전에 배포된 자동 업데이트 활성 빌드는 새 빌드로 교체하기 전까지 Expo EAS Update에 접속할 수 있습니다. 이때 운영체제·앱 업데이트 정보와 앱 설치별 무작위 식별자가 전송되며, 오류 복구 과정에서는 오류 정보도 전송될 수 있습니다. 접속 과정에서 IP 주소가 처리될 수 있습니다. 생년월일을 업데이트 요청에 넣지는 않습니다.

이전 빌드의 업데이트 통신 처리는 Expo 개인정보 정책을 따릅니다. 해당 서비스의 정보가 요청 직후 모두 삭제된다고 보장하지 않습니다. 이전 방침의 「앱 버전만 오간다」는 설명은 위와 같이 정정합니다.

이용자가 개인정보 처리방침 같은 외부 링크를 누르면 브라우저가 열립니다. 외부 페이지 접속과 실제 메시지 전송은 인터넷 연결이 필요할 수 있으며, 해당 서비스의 개인정보 정책이 적용됩니다.

6. 공유 기능

궁합 결과를 이미지 카드로 만들어 공유할 수 있습니다. 이 카드는 기기 안에서 만들어져 운영체제의 공유 기능으로 전달되며, 개발자의 서버를 거치지 않습니다.

카드에는 두 사람의 띠 이름과 그림, 관계 문안이 들어가며 생년월일은 들어가지 않습니다. 신수첩이 카드를 사진첩에 직접 저장하지 않고 사진 접근 권한도 요청하지 않습니다. 공유 시트에서 고른 앱의 저장·전송 방식은 그 앱의 정책을 따릅니다.

7. 결제

1.2.0부터 신년 운세 한 가지를 유료로 팝니다. 나머지 기능 — 오늘의 신수, 띠 궁합, 토정비결 총운과 달별 풀이, 날짜 고르기, 절기, 내 사람들 — 은 모두 무료입니다.

결제 자체는 Google Play 또는 App Store가 처리합니다. 카드 번호와 결제 수단은 신수첩이 받지도 보지도 않습니다.

구매 여부를 확인하고 기기를 바꿨을 때 되살리기 위해 결제 처리 도구 RevenueCat을 씁니다. 이 도구에는 구매한 상품과 영수증 확인에 필요한 정보, 그리고 설치할 때 만들어진 무작위 번호가 전달됩니다. 이름·이메일·생년월일은 전달하지 않습니다. 처리는 RevenueCat 개인정보 정책을 따릅니다.

2절의 익명 사용 통계에는 결제 화면을 몇 번 열고 구매 단추를 몇 번 눌렀는지, 그 결과가 성공·취소·실패 가운데 무엇이었는지만 보냅니다. 금액·영수증·주문 번호는 보내지 않습니다.

구독이 아닙니다. 한 번 사면 그 해의 풀이를 계속 볼 수 있고, 저절로 다시 결제되지 않습니다.

8. 권한

신수첩은 카메라, 마이크, 위치, 연락처, 사진에 대한 접근 권한을 요청하지 않습니다.

알림은 설정에서 알림을 켤 때에만 권한을 청합니다. 첫 실행에는 묻지 않습니다. 오늘의 신수·절기·손 없는 날·삼재 알림은 모두 기기에서 예약하는 로컬 알림이라 푸시 서버도 토큰도 쓰지 않으며, 알림을 위해 어떤 정보도 전송하지 않습니다. 거절하거나 나중에 꺼도 다른 기능은 그대로 쓸 수 있습니다.

인터넷 통신 권한은 위 2절의 익명 사용 통계를 보내기 위해 쓰입니다.

9. 아동의 개인정보

아동을 대상으로 정보를 수집하는 기능은 없습니다. 입력값의 기기 내 처리와 이전 빌드의 업데이트 통신은 위에서 설명한 방식으로 이루어집니다.

10. 방침의 변경

이 방침이 바뀌면 이 페이지에서 개정일과 함께 알려 드립니다. 앞으로 광고 등으로 데이터 처리가 생기는 경우, 변경 사항을 앱 업데이트 전에 이 페이지에 먼저 반영합니다.
